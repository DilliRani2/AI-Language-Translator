# 🌐 AI Language Translator

An AI-powered language translation project built using Python and Hugging Face Transformers. This project explores multilingual text translation using a pretrained model.

## ✨ Features

- Translates text between supported languages.
- Uses a pretrained multilingual translation model.
- Demonstrates Transformer-based language translation.
- Provides hands-on experience with Hugging Face.

## 🛠️ Technologies Used

- Python
- Hugging Face Transformers
- PyTorch
- Jupyter Notebook
- Google Colab

## 🚀 Installation and Usage

### 1. Clone the repository

```bash
git clone https://github.com/DilliRani2/AI-Language-Translator.git
cd AI-Language-Translator
```
### 2. Run the notebook

Open the notebook using Jupyter Notebook or Google Colab.

To use Jupyter Notebook locally:

```bash
pip install notebook
jupyter notebook
```

Open `AI_Translator_Dilli_rani_(12_10_26)_.ipynb` and execute the cells in order.
